# ADR-001: Use Next.js App Router

## Status

Accepted

## Context

The project requires excellent SEO, modern React features, server rendering, and long-term scalability.

## Decision

Use Next.js with the App Router.

## Alternatives Considered

* React + Vite
* Remix
* Astro

## Consequences

### Positive

* Excellent SEO
* React Server Components
* Optimized routing
* Strong deployment ecosystem

### Negative

* Learning curve for new developers
* React Server Components require understanding of server/client boundaries
