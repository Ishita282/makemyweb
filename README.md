# MakeMyWeb

> Build the business your customers deserve.

MakeMyWeb is a premium digital product partner helping businesses launch, grow, and scale through modern websites, web applications, mobile applications, AI solutions, eCommerce platforms, and digital marketing.

This repository contains the official source code for the MakeMyWeb marketing website.

---

## Vision

Create a flagship digital experience that demonstrates world-class craftsmanship while generating qualified leads for high-value client projects.

---

## Core Principles

* Business-first thinking
* Design with purpose
* Accessibility by default
* Performance first
* Reusable architecture
* Scalable design system
* Documentation-driven development

---

## Technology Stack

* Next.js (App Router)
* TypeScript
* Tailwind CSS
* React
* Motion
* React Hook Form
* Zod
